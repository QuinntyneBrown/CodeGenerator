# Support

## Getting help

Before requesting help:

1. Review the [README](README.md) and relevant package documentation.
2. Search [existing issues](https://github.com/QuinntyneBrown/CodeGenerator/issues) for the same behavior.
3. Confirm the issue still occurs with the latest applicable package and a supported .NET SDK.
4. Reduce the problem to the smallest model, template, or command that reproduces it.

Use the [issue chooser](https://github.com/QuinntyneBrown/CodeGenerator/issues/new/choose) to report a reproducible bug or propose a scoped feature.

A useful report includes:

- The affected package and version
- Operating system and .NET SDK version
- Target-specific tool versions, such as Node.js or Python, when relevant
- The input model, template, YAML configuration, or CLI command
- Expected and actual behavior
- A minimal reproduction
- Sanitized logs, diagnostics, or generated output

Please format code and logs as text rather than screenshots when possible. Never post credentials, access tokens, private source code, customer data, or unredacted sensitive logs.

## Support policy

Support is provided by maintainers and contributors on a best-effort basis. This project does not include a service-level agreement, guaranteed response time, consulting engagement, or production operational support.

## Security and conduct

- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
- Report conduct concerns through the private channel in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
